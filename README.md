# 两端的灯

一个两个人用手机联机玩的剧情解谜游戏。一个人在晨岸，一个人在暮港，两人看到的画面不一样，要靠互相描述来解谜。共 8 章、37 个谜题，全程大约 6 到 8 小时。

## 怎么玩

1. 两个人都用手机浏览器打开游戏网址。
2. 一个人点「创建新房间」，把 4 位房间号告诉对方。
3. 另一个人输入房间号，点「加入对方的房间」。
4. 各选一个角色，起好名字，点「准备好了」。
5. 建议边打语音边玩。第六章除外，那一章要关掉语音，只用表情按钮交流。

每读完一段剧情、解开一个谜题都会自动存档。下次用同一部手机打开网址，会自动回到你们的房间。右上角菜单里可以重玩已经解锁的章节。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `server.js` | 联机服务器，不需要安装任何依赖 |
| `public/story/ch1.js` 到 `ch8.js` | 八章剧情和谜题设置，改台词就改这里 |
| `public/custom.js` | 结局的专属彩蛋信，写好之后会在终章出现 |
| `public/logic.js` | 游戏规则（两边共用） |
| `public/game.js` | 手机上的画面和操作 |
| `public/art.js` | 占位美术（用代码画的场景），以后可以换成正式画稿 |
| `public/style.css` | 样式 |
| `tools-check.js` | 检查剧情有没有断掉、迷宫能不能走通：`node tools-check.js` |
| `build-preview.py` | 打包成单机预览网页（一台设备同时看两边） |

## 在自己电脑上运行

装好 Node.js（18 或更新的版本）之后：

```
node server.js
```

然后打开 http://localhost:8080 。在网址后面加 `?preview` 可以在一个页面里同时看到两个人的画面。

## 放到网上

服务器只需要能运行 Node.js 的地方，不需要数据库。进度会保存在 `data/rooms.json`；就算免费主机重启把这个文件弄丢了，玩家手机里也存着最后的进度，重新打开时会自动恢复。

可以改的环境变量：

- `PORT`：端口，默认 8080
- `DATA_DIR`：存档放在哪个文件夹，默认 `data/`
